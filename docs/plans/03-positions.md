# 方案三：编辑部职位

状态：**已批准并完成**（2026-10-17）。职位列表按原样采用；第十一节的后台改动已做：人员资料里的 Positions 下拉多选（只有超级管理员和有人员权限的人能改），按职位提示建议的后台等级和权限（不会自动提权），没写 Title 时用职位作为署名头衔，网站 Our Staff 页面和纸质版编辑部名单按职位分组和排序。启用哪些职位由你们按人数决定（见第十节）。

这份方案按真实报社的分工设计，规模适合高中校报。每个职位写明了职责、能力要求、每周投入时间、汇报对象，以及在 BOSS Today 后台里对应的等级和专项权限（见方案一）。

职位名称用英文，因为它们会出现在网站署名、作者页和纸质版的编辑部名单里。

## 一、编辑部领导（Masthead）

### Editor-in-Chief · 主编

报纸的最终负责人，对刊出的每一个字负责。

- **职责**
  - 决定每期的报道方向和头版，主持每周编辑会议。
  - 对敏感、有争议的稿件做最终发布决定，必要时与指导老师商量。
  - 代表校报与校方、学生会、社团和外部媒体沟通。
  - 任命和考核各版块编辑，处理编辑部内部分歧。
  - 维护报纸的独立性和公信力，签发更正声明。
- **能力**：有判断力和担当；写作和编辑能力突出；能在截稿压力下做决定；在校报至少工作过一年。
- **每周投入**：5–8 小时，出刊周更多。
- **汇报对象**：指导老师。
- **后台**：超级管理员，或拥有全部四项专项权限的 Exec。

### Managing Editor · 执行主编

让编辑部按时运转的人：主编管"做什么"，执行主编管"怎么按时做完"。

- **职责**
  - 制定和跟进出刊日程，追踪每篇稿件处在哪个阶段（草稿、待审、退回、已发布）。
  - 协调各版块之间的人手和版面冲突。
  - 主编不在时代行主编职责。
  - 每期结束后组织复盘：哪里拖了、哪里出错了。
- **能力**：组织能力强，靠谱，善于催人但不得罪人。
- **每周投入**：4–6 小时。
- **汇报对象**：主编。
- **后台**：Exec，专项：人员、纸质版。

### Faculty Advisor · 指导老师

不是学生职位，但必须列出来。

- **职责**
  - 在法律、隐私和学校政策问题上提供意见。
  - 处理需要校方介入的事务，例如数字工具审批、投诉。
  - 学生换届时保证网站和账号的延续。
- **后台**：建议设为**超级管理员**。学生会毕业，老师在，这样不会因为某届主编离校而没人能进后台。

## 二、版块编辑（Section Editors）

每个版块编辑管理自己版块的记者，从选题到发稿全程负责。以下六个职位对应网站现有的六个栏目。

### News Editor · 新闻编辑

- **职责**
  - 盯住学校的重要动态：校方政策、学生会决定、校园设施、重大活动。
  - 给记者分配选题和采访对象，确保报道有多方信源、事实准确、平衡。
  - 审稿时重点检查：引语是否准确、有没有遗漏的关键方、标题是否夸大。
  - 有突发新闻时快速组织报道并发布网络版。
- **能力**：新闻敏感度；了解学校的运作方式；能分辨事实和传言。
- **每周投入**：3–5 小时。
- **汇报对象**：主编。
- **后台**：Editor。

### Opinion Editor · 评论编辑

- **职责**
  - 组织社论（代表报社立场的文章）的讨论和撰写，主持编委会。
  - 约稿和管理专栏作者，处理读者来信。
  - 确保评论文章论点清楚、论据真实，标明是观点而不是新闻。
  - 把关言论边界：可以尖锐，但不能人身攻击或针对未成年个人。
- **能力**：逻辑清晰；能接受不同观点；文字有说服力。
- **每周投入**：3–4 小时。
- **汇报对象**：主编。
- **后台**：Editor。

### Student Life Editor · 校园生活编辑

- **职责**
  - 负责人物特写、社团介绍、校园活动、学生故事等深度内容。
  - 指导记者做长篇采访和叙事写作，而不只是罗列事实。
  - 关注平时没人报道的群体和角落，让更多学生被看见。
- **能力**：好奇心强，擅长讲故事，能让采访对象放松。
- **每周投入**：3–4 小时。
- **汇报对象**：主编。
- **后台**：Editor。

### Sports Editor · 体育编辑

- **职责**
  - 覆盖学校各运动队的赛季：赛程、比分、关键比赛、运动员专访。
  - 和教练、队长保持联系，及时拿到比赛结果。
  - 安排记者和摄影到现场，赛后尽快发布赛况。
  - 每季做一次赛季回顾或数据总结。
- **能力**：了解多项运动的规则；能在比赛结束后快速写稿。
- **每周投入**：3–5 小时，赛季期间更多。
- **汇报对象**：主编。
- **后台**：Editor。

### Arts & Culture Editor · 文艺编辑

- **职责**
  - 报道学校的音乐、戏剧、美术、舞蹈演出和展览。
  - 组织书评、影评、乐评等评论，并制定评论标准（例如评分方式）。
  - 展示学生的原创作品，如诗歌、摄影、绘画。
- **能力**：有审美和表达能力，熟悉至少一种艺术形式。
- **每周投入**：2–4 小时。
- **汇报对象**：主编。
- **后台**：Editor。

### Science & Tech Editor · 科技编辑

- **职责**
  - 报道学校的科学竞赛、机器人队、编程社团、科研项目。
  - 用学生能懂的语言解释科技新闻和它对高中生的影响。
  - 把关科学事实的准确性，必要时请老师审核。
- **能力**：理科背景；能把复杂概念讲简单。
- **每周投入**：2–4 小时。
- **汇报对象**：主编。
- **后台**：Editor。

## 三、记者与作者（Reporters & Writers）

### Senior Reporter · 资深记者

- **职责**
  - 长期跟一个固定领域（"条线"），例如学生会、校方行政、某支运动队。
  - 独立完成从找选题、采访到成稿的全过程，承担大型或调查性报道。
  - 带新记者出去采访，示范怎么提问、怎么记录。
- **能力**：至少在校报写过一年，有多篇已发表的稿件。
- **每周投入**：3–4 小时。
- **汇报对象**：所在版块编辑。
- **后台**：Reporter。

### Staff Writer · 记者

- **职责**
  - 每两到三周完成一篇编辑分配的稿件。
  - 采访至少两位信源，准确记录引语，交稿前自己核对一遍事实。
  - 按编辑的退回意见修改稿件。
- **能力**：基本写作能力，守时，愿意接受修改意见。
- **每周投入**：2–3 小时。
- **汇报对象**：所在版块编辑。
- **后台**：Reporter。

### Columnist · 专栏作者

- **职责**
  - 拥有一个固定专栏（例如每两周一篇），以个人视角评论校园或社会话题。
  - 保持专栏风格和主题的一致性，建立自己的读者群。
- **能力**：有鲜明观点和个人文风；能稳定产出。
- **每周投入**：2 小时。
- **汇报对象**：评论编辑。
- **后台**：Reporter。

### Junior Reporter · 见习记者

给九、十年级新成员的入门职位。

- **职责**
  - 参加写作培训，先从短讯、活动报道、赛况开始写。
  - 跟资深记者一起采访，学习流程。
  - 完成三篇已发表的稿件后，可以申请升为 Staff Writer。
- **能力**：有兴趣就行。
- **每周投入**：1–2 小时。
- **汇报对象**：所在版块编辑。
- **后台**：Reporter。

### Contributing Writer · 特约作者

- **职责**：不固定参与编辑部工作，偶尔投一篇稿，例如运动员写赛季感想、社团负责人写活动回顾。
- **后台**：Reporter。投稿结束后可以取消勾选 Active，署名会保留。

## 四、编校与标准（Copy & Standards）

报纸的公信力主要靠这一组人守住。

### Copy Chief · 编校主任

- **职责**
  - 制定并维护《BOSS Today 写作规范》：日期写法、数字、人名头衔、标点、常见错误。
  - 分配每篇稿件的校对人，保证发布前至少经过一次完整的校对。
  - 培训校对员，统计常见错误并在编辑会议上提醒。
- **能力**：对文字细节非常敏感，熟悉英语语法和新闻写作规范（如 AP Style）。
- **每周投入**：3–4 小时。
- **汇报对象**：执行主编。
- **后台**：Editor。

### Copy Editor · 校对编辑

- **职责**
  - 检查拼写、语法、标点和是否符合写作规范。
  - 精简啰嗦的句子，修改不准确或有歧义的标题和摘要。
  - 有疑问的地方标注出来退回作者确认，而不是自己猜。
- **每周投入**：2–3 小时。
- **汇报对象**：编校主任。
- **后台**：Editor（需要能修改别人的稿件）。

### Fact-Checker · 事实核查员

- **职责**
  - 逐条核对稿件中的名字、职位、日期、数字和引语。
  - 必要时联系信源确认，核查结果记录在稿件的编辑意见里。
  - 调查性报道和涉及具体人物的批评性报道，必须经过核查才能发布。
- **能力**：细心、有耐心、不怕打电话或发邮件求证。
- **每周投入**：2–3 小时。
- **汇报对象**：编校主任。
- **后台**：Editor。

### Standards Editor · 标准与伦理编辑

校报特有的重要职位：读者和被报道的人大多是未成年人。

- **职责**
  - 制定和执行报道伦理：何时可以匿名、如何报道未成年人、如何处理照片里的学生。
  - 审查涉及心理健康、纪律处分、家庭隐私等敏感话题的稿件。
  - 处理读者的投诉和更正请求，决定是否刊登更正，并在后台记录。
  - 每学期回顾一次已发布内容中的问题。
- **能力**：成熟稳重，有同理心，能和指导老师密切配合。
- **每周投入**：1–3 小时。
- **汇报对象**：主编。
- **后台**：Editor（有权撤稿）。

## 五、视觉（Visuals）

### Photo Editor · 图片编辑

- **职责**
  - 为每篇稿件安排拍摄或挑选图片，保证每张图都有说明文字和摄影署名。
  - 管理后台图片库：删除重复和不合格的图片，保持图片说明准确。
  - 把关拍摄伦理：拍学生要征得同意，不发布让人难堪的照片。
  - 培训摄影记者的构图和现场拍摄技巧。
- **能力**：摄影和修图能力；了解肖像权和拍摄同意。
- **每周投入**：3–4 小时。
- **汇报对象**：主编。
- **后台**：Exec，专项：图片库。

### Staff Photographer · 摄影记者

- **职责**
  - 按图片编辑的安排到活动和比赛现场拍摄。
  - 拍摄后 48 小时内交图，附上说明（谁、在做什么、在哪里）。
- **能力**：会用相机或手机拍出清晰、有构图的照片。
- **每周投入**：2–3 小时。
- **汇报对象**：图片编辑。
- **后台**：Reporter（可上传图片）。

### Graphics & Illustration Editor · 图表与插画编辑

- **职责**
  - 为没有合适照片的稿件绘制插画。
  - 把数据（例如调查结果、比赛数据）做成清楚的图表。
  - 设计专栏头图和特别报道的视觉风格。
- **能力**：插画或平面设计能力，会用 Canva、Procreate 或 Illustrator 等工具。
- **每周投入**：2–3 小时。
- **汇报对象**：图片编辑。
- **后台**：Reporter。

## 六、版面与印刷（Print & Design）

### Print Editor · 纸质版主编

- **职责**
  - 每期从已发布的稿件中选稿，决定纸质版的顺序、每篇占几栏、是否配图。
  - 在后台创建期刊、设置公告和纸张大小，导出 PDF 并检查每一页。
  - 负责和印刷方（学校打印室或印刷厂）对接、确认印数和发放。
  - 等小组的版面设计稿完成后，负责让纸质版符合设计规范。
- **能力**：版面感，细心，能按时出刊。
- **每周投入**：出刊周 4–6 小时，平时 1 小时。
- **汇报对象**：执行主编。
- **后台**：Exec，专项：纸质版。

### Layout Designer · 版面设计

- **职责**
  - 设计报纸的视觉规范：字体、栏宽、标题层级、报头。
  - 检查纸质版 PDF：标题是否断行难看、图片是否被裁坏、页面是否留白过多。
  - 协助设计海报、招新物料。
- **能力**：平面设计基础。
- **每周投入**：2–3 小时。
- **汇报对象**：纸质版主编。
- **后台**：Reporter（只需预览，不需编辑他人稿件）。

## 七、数字与多媒体（Digital & Multimedia）

### Digital Editor · 网站主编

- **职责**
  - 管理网站头版：决定头条和头版稿件，随新闻变化及时更新。
  - 管理栏目设置、站点设置（About 页面、社交链接）。
  - 检查每篇稿件在网站和手机上的显示效果，标题和摘要是否适合网络阅读。
  - 每月查看阅读数据，提出改进建议。
- **能力**：熟悉网络阅读习惯，细心。
- **每周投入**：2–4 小时。
- **汇报对象**：主编。
- **后台**：Exec，专项：头版。

### Video Producer · 视频制作

- **职责**
  - 拍摄和剪辑短视频：活动集锦、采访、比赛精彩瞬间。
  - 上传到报社的 YouTube 频道，并嵌入相应的网站稿件。
  - 保证视频里出现的学生知情同意。
- **能力**：拍摄和剪辑能力（如 CapCut、Premiere）。
- **每周投入**：2–4 小时。
- **汇报对象**：网站主编。
- **后台**：Reporter。

### Social Media Editor · 社交媒体编辑

- **职责**
  - 运营报社的社交媒体账号（如 Instagram），每篇重要稿件发布后配图推送。
  - 制定发布节奏，回复评论和私信，把读者线索转给相关编辑。
  - 确保社交媒体上的内容同样经过审核，不发未核实的消息。
- **能力**：了解同龄人的媒体习惯，文字简洁有吸引力。
- **每周投入**：2–3 小时。
- **汇报对象**：网站主编。
- **后台**：Reporter。

## 八、运营（Operations）

### Recruitment & Training Coordinator · 招新与培训

- **职责**
  - 组织每学期的招新：海报、宣讲、试写。
  - 在后台给新成员建账号、设初始密码、分配等级。
  - 为新人组织入门培训：采访技巧、写作规范、后台使用。
  - 学生毕业或退出时，取消勾选账号的 Active（保留署名）。
- **能力**：外向，有耐心，有组织能力。
- **每周投入**：招新期 3–4 小时，平时 1 小时。
- **汇报对象**：执行主编。
- **后台**：Exec，专项：人员。

### Web & Tech Lead · 网站技术负责人

- **职责**
  - 维护网站的技术部分：Vercel 部署、数据库、Google 登录、图片仓库。
  - 处理技术故障，跟进网站的功能改进。
  - 每年换届时，确保下一任能接手账号和文档。
- **能力**：基础编程或愿意学习，有责任心。
- **每周投入**：1–2 小时，有问题时更多。
- **汇报对象**：主编。
- **后台**：Exec，四项专项全部；Vercel 和 GitHub 的访问权限由超级管理员授予。

### Archivist · 档案管理

- **职责**
  - 整理历届纸质版 PDF 和重要报道，维护期刊列表的完整性。
  - 每学期末备份纸质版 PDF 到学校共享盘。
  - 在校庆或纪念日策划"回顾"专题。
- **每周投入**：约 1 小时。
- **汇报对象**：执行主编。
- **后台**：Reporter。

## 十、按规模启用

不需要一开始就把所有职位填满。

| 编辑部人数 | 建议设置的职位                                                                 |
| ---------- | ------------------------------------------------------------------------------ |
| 10 人以内  | 主编、执行主编、2–3 个版块编辑（可以一人兼两个版块）、编校主任、图片编辑、记者 |
| 10–25 人   | 加上全部六个版块编辑、网站主编、纸质版主编、校对编辑、摄影记者                 |
| 25 人以上  | 全部职位，包括标准与伦理编辑、事实核查员、视频、社交媒体、招新与培训           |

一人兼任多个职位没有问题，例如执行主编兼招新与培训。

## 十一、后台可以配合做的改动（可选）

批准职位后，可以把人员资料里的"职位"从自由填写改成**下拉选择**：

- 选择职位时，系统自动建议对应的后台等级和专项权限。仍由超级管理员确认，不会自动提权。
- 纸质版的编辑部名单按上面的分组排列（领导层、版块编辑、编校、视觉……），而不是按姓名排序。
- 作者页显示职位的说明。
- 一人兼任多职时，可以选多个职位。

## 需要你决定
