# 方案一：用户等级

状态：**已批准并实现**（2026-10-14）。

## 五个等级

| 等级 | 英文名 | 能做什么 | 账号怎么来 |
|---|---|---|---|
| 1 普通人 | Reader | 登录网站，不能进后台。读文章本身不需要登录 | 用学校 Google 账号首次登录时自动创建 |
| 2 记者 | Reporter | 写自己的稿、传图、提交审核。不能发布；稿件发布后不能再改 | 由有"人员"权限的管理员提升 |
| 3 编辑 | Editor | 改所有稿件、审核、发布和撤稿 | 同上 |
| 4 管理员 | Exec | 编辑的全部权限，加上被分配的专项权限 | 由超级管理员任命 |
| 5 超级管理员 | Super Admin | 全部权限；任免管理员并分配专项 | 写在部署配置里（环境变量） |

## 管理员的专项权限

每位管理员勾选一项或多项，只能操作勾选的部分：

| 专项 | 能做什么 |
|---|---|
| 头版 | 决定头条和头版稿件，管理栏目 |
| 纸质版 | 创建期刊、选稿排序、发布纸质版 |
| 人员 | 邀请和移除记者、编辑，调整他们的等级 |
| 图片库 | 删除和整理所有图片 |

## 规则

- 只能任免比自己低的等级。
- 任何人都不能修改自己的等级。
- 超级管理员由环境变量 `SUPER_ADMIN_EMAILS` 指定，后台里不能被降级或删除，避免所有人被误删后没人能进后台。
- 学生毕业后，账号改为"已停用"而不是删除，这样旧文章的署名和作者页仍然保留。

| 操作 | 普通人 | 记者 | 编辑 | 管理员 | 超级管理员 |
|---|---|---|---|---|---|
| 读已发布文章 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 进入后台 | | ✓ | ✓ | ✓ | ✓ |
| 写自己的草稿、传图 | | ✓ | ✓ | ✓ | ✓ |
| 修改别人的稿件 | | | ✓ | ✓ | ✓ |
| 发布、撤稿 | | | ✓ | ✓ | ✓ |
| 编排头版、管理栏目 | | | | 需"头版" | ✓ |
| 期刊与纸质版 | | | | 需"纸质版" | ✓ |
| 管理记者和编辑 | | | | 需"人员" | ✓ |
| 删除任意图片 | | | | 需"图片库" | ✓ |

## 数据量

每个账号只存姓名、邮箱、等级，约 1 KB。全校两千人都登录过也只有约 2 MB，是 Neon 免费额度（1 GB）的千分之二。

## 已定的选项

1. **普通人账号**：已实现，但默认关闭。在 Vercel 设置 `ALLOW_READER_SIGNUP=true` 即可开放。
2. **编辑**：不按栏目划分。
3. **专项权限**：头版、纸质版、人员、图片库四项。
4. **登录邮箱**：只允许 `@gapps.yrdsb.ca` 和 `@yrdsb.ca`（可用 `ALLOWED_EMAIL_DOMAINS` 修改）。超级管理员不受限制。
