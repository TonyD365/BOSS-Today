# 方案六：网站设计器（自由画布）

状态：**待批准**（2026-10-16 按"自由画布"重写）

## 目标

在后台里像 Canva 一样，**自由拖放、缩放**首页上的东西，自己设计版面。这个功能单独设一个 **Design（网站设计）** 权限，像 Issue 权限一样单独授予。

## 一、设计器长什么样

后台新增一个页面 **Site designer**，分三栏：

| 左边：元素                       | 中间：画布                             | 右边：属性                       |
| -------------------------------- | -------------------------------------- | -------------------------------- |
| 可以拖到画布上的东西（见第二节） | 首页的样子，用的是**真实的稿件和图片** | 选中一个元素后，调它的内容和样式 |

- **拖动**移动，拖四角**缩放**，按住 Shift 等比例缩放。
- 自动吸附：靠近其他元素的边缘或中线时会对齐，并显示参考线；也可以吸附到网格上。
- **图层**：元素可以重叠，可以"置于顶层 / 置于底层"。左下角有图层列表，可以锁定、隐藏。
- **撤销 / 重做**（Ctrl+Z / Ctrl+Shift+Z）、复制、粘贴、多选、键盘方向键微调。
- 顶部可以切换 **电脑版 / 手机版**（见第三节），以及缩放画布大小。

## 二、可以放的元素

| 元素                            | 内容                                              | 可以调的样式                                        |
| ------------------------------- | ------------------------------------------------- | --------------------------------------------------- |
| **稿件卡片**                    | 指定某篇稿件，或"某栏目最新第 N 篇"（会自动更新） | 显示/隐藏图片、摘要、作者；标题字号；图片在上/左/右 |
| **标题文字**                    | 自己写的一段大字，比如专题标题                    | 字体、字号、粗细、颜色、对齐                        |
| **文字框**                      | 一段说明                                          | 同上                                                |
| **图片**                        | 从媒体库选，可以加链接                            | 裁剪方式、圆角、说明文字                            |
| **形状**                        | 矩形、线条，用作背景色块或分隔线                  | 颜色、粗细、圆角                                    |
| **栏目列表**                    | 某个栏目最新的几篇                                | 篇数、有无图片                                      |
| **最新 / 最热**                 | Latest 或 Most read 列表                          | 条数                                                |
| **比分 / 本周活动 / LIVE 入口** | 第四批的三个小板块                                | 条数                                                |
| **期刊封面**                    | 最新一期的纸质版和下载链接                        |                                                     |

颜色只能从一套**预先挑好的报纸配色**里选，字体只能从 4–5 套搭配好的组合里选，保证整个网站风格统一、文字看得清。

## 三、手机怎么办（最关键）

自由摆放的版面，在窄屏幕上不能直接缩小，否则字会小得看不清。所以：

1. **电脑和平板**：网站按电脑版画布**等比例缩放**。屏幕越窄，整个版面（包括文字）一起缩小，位置关系完全不变，看到的就是设计的样子。
2. **手机**（屏幕宽度小于 768 像素）：用单独的**手机版画布**。
   - **默认自动生成**：系统把电脑版的元素按"从上到下、从左到右"排成一列，宽度占满屏幕。
   - **可以手动调整**：在设计器里切到"手机版"，同样可以拖动、缩放、隐藏某些元素。手动调过的位置会记住；之后电脑版新加的元素，会自动排到手机版的最下面，并提示你去看一眼。
   - 发布前，检查清单会提醒："电脑版在上次检查手机版之后改过，请确认手机版"。

## 四、防止排坏

- **文字装不下**：稿件标题比框长时，网站上会在末尾显示省略号。设计器里这个框会**标红**，提醒你放大框或缩短标题。因为用的是真实内容，所以看到的就是读者会看到的。
- **"某栏目最新第 N 篇"换稿以后**：新标题可能变长。每次发布期刊前，检查清单会用新内容再检查一遍，有装不下的就列出来。
- **对比度**：文字颜色和背景太接近时，设计器会警告，不能保存。
- **读屏顺序**：盲人用的读屏软件，按"从上到下、从左到右"的顺序朗读，也可以在图层列表里手动调整。
- **没有设计时**：如果还没发布过任何设计，或者设计出错，网站自动使用现在的经典首页，不会出现空白页。
- **报头、导航栏、页脚保持统一**，不在画布里（见"需要你决定"第 2 条）。这样不管首页怎么设计，读者都能找到栏目、搜索和其他页面。

## 五、权限和上线

- 新增专项权限 **Design（网站设计）**，可以授予 Editor 和 Exec，由超级管理员分配。超级管理员始终有这个权限。
- 没有 Design 权限的人能打开设计器看，但不能改。
- 改动存为**草稿**，**默认跟下一期一起上线**。期刊发布检查清单里会列出"网站设计有改动"，发布人确认后一起发布。
- 急着换的话，有 Issue 权限的人可以点 **"Publish design now"**，单独发布设计，占本月 400 次部署里的 1 次，必须写原因。
- 保留最近 10 个已发布的设计，可以**一键恢复**。
- 可以把当前设计**另存为模板**（比如"返校周""选举特刊"），下次直接套用。

## 六、技术上

- 设计保存成一份数据：每个元素的类型、位置、大小、层级和样式。服务器保存前会检查，只接受允许的元素类型、颜色和链接，防止有人塞进恶意代码。
- 构建网站时，Cloudflare 按这份数据生成首页：电脑版用等比例缩放的画布，手机版用手机画布，两者根据屏幕宽度自动切换。
- 设计器主要在浏览器里运行，拖动、缩放都不经过服务器，**不怎么耗 Vercel 的 CPU**。只有打开设计器和保存草稿时会请求服务器。
- 拖动和缩放用一个开源的小工具库实现，不需要任何付费服务。

## 七、分两步做

- **第一步**：设计器（拖动、缩放、吸附、图层、撤销）、第二节的全部元素、电脑版和手机版、检查清单里的提醒、Design 权限、发布和恢复。上线时，现有首页会被自动转换成一份画布设计，所以外观不变，直到有人去改。
- **第二步**：自定义页面（用同样的画布做 "About us""Join us" 等页面）、整站配色字体设置、模板。

工作量很大，比方案五的任何一批都大。第一步做完、测试过、上线后，再做第二步。

## 需要你决定

1. **手机版**：同意"默认自动生成、可以手动调"吗？（另外两种做法：每次都必须手动排，或者只自动、不能调。）
2. **画布范围**：只设计首页正文、报头导航页脚保持统一（推荐）；还是报头导航也能自由设计？
3. **Front Page 权限**：并入 Design（推荐），还是两个分开？分开的话，Front Page 只管"放哪几篇稿件"。
4. **上线方式**：同意"默认跟下一期，有 Issue 权限的人可以立即发布、占 1 次部署"吗？
5. **第二步**里的自定义页面、整站配色字体、模板，都要吗？
