# 方案七：把后台从 Vercel 搬走

状态：**待批准**（2026-10-16）

## 为什么要搬

Vercel 免费版每月只有 **4 小时 CPU**。编辑部 100 人一起用后台，估计每月要 4–8 小时，很可能不够。超了以后后台会被暂停，到下个月才能恢复。

**只搬后台。** 读者网站继续放在 Cloudflare Pages 上，不受影响。数据库继续用 Neon，也不用动。

## 一、可选的平台

| 平台                                         | 费用            | 能力                                                                                      | 缺点                                                                                               |
| -------------------------------------------- | --------------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Google Cloud Run**（推荐）                 | 免费额度内 0 元 | 每月 **50 小时** CPU（Vercel 的 12 倍），200 万次请求；一段时间没人用时自动关机，不占资源 | 注册要绑**信用卡**（只用于验证，不超额不扣钱）；没人用一阵后，第一个打开后台的人要等 5–10 秒       |
| **Oracle Cloud 永久免费服务器**              | 0 元            | 最强：4 核 24 GB 内存的整台服务器，基本用不完                                             | 也要信用卡验证；整台服务器要自己维护（系统更新、安全），出了问题要有人会处理；长时间闲置可能被回收 |
| **Cloudflare Workers 付费版**                | 每月 5 美元     | 全部放在 Cloudflare，和读者网站在一起；额度很大                                           | 要付钱；后台程序要大改：图片处理和 PDF 生成在那里不能直接用，要换别的做法                          |
| **Render 免费版**                            | 0 元            | 不用信用卡                                                                                | 只有 512 MB 内存，后台可能跑不稳；15 分钟没人用就休眠，再打开要等约 1 分钟                         |
| **学校或家里的一台电脑** + Cloudflare Tunnel | 0 元            | 没有任何额度限制                                                                          | 电脑要一直开着；断电、断网、关机，后台就用不了                                                     |

## 二、我的推荐：Google Cloud Run

- **额度够用。** 每月 50 小时 CPU，按方案里最重的估计（8 小时）也只用到六分之一。
- **基本不用维护。** 和 Vercel 一样，推送代码就自动部署，不用管服务器。
- **PDF 和图片处理照常能用。** 程序会打包成一个"容器"，里面自带生成 PDF 用的浏览器。
- **防止扣钱。** 我会教你设置一个 1 美元的预算提醒，并限制最多同时开几台，这样就算有人刷后台也超不了。正常使用不会产生任何费用。
- **缺点**：注册要一张信用卡（可以用家长的）；后台闲置一段时间后，第一个打开的人要等几秒。

**如果没办法绑卡**：退而求其次是**学校的电脑 + Cloudflare Tunnel**，前提是有一台能一直开机的电脑（比如社团老师的办公室电脑）。Render 免费版内存太小，不推荐。

## 三、要改的东西

| 项目         | 现在                           | 搬家后                                                                                                           |
| ------------ | ------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| 后台和接口   | Vercel                         | Cloud Run（地址类似 `boss-today-xxxx.run.app`，以后可以换成自己的域名）                                          |
| 自动部署     | 推送到 main 后 Vercel 自动部署 | 推送到 main 后，GitHub 自动打包并部署到 Cloud Run                                                                |
| 数据库迁移   | Vercel 构建时运行              | 部署时自动运行                                                                                                   |
| 每日定时任务 | Vercel Cron                    | Google Cloud Scheduler（免费 3 个任务）                                                                          |
| 图片         | Vercel Blob                    | 建议改存 **Cloudflare R2**：免费 10 GB，下载流量不收费。现有图片由我写脚本一次性搬过去，文章里的图片地址自动更新 |
| 纸质版 PDF   | Vercel 现场生成                | Cloud Run 现场生成（不变）                                                                                       |
| Google 登录  | 回调地址是 Vercel 的           | 在 Google Cloud 里加上新地址                                                                                     |
| 读者网站     | 从 Vercel 拉文章               | 改成从 Cloud Run 拉（Cloudflare Pages 里改一个环境变量）                                                         |

## 四、怎么搬才不出事

1. 我先把程序改成能在 Cloud Run 上运行，同时**保持 Vercel 照常可用**。
2. 你注册 Google Cloud，按我写的步骤一步步设置（我会写得很详细）。
3. 先部署一个测试版，连的是同一个数据库。确认登录、写稿、上传图片、发布期刊、生成 PDF 都正常。
4. 选一个没人用后台的时间（比如周末晚上）**正式切换**：搬图片 → 改 Cloudflare 和 Google 登录的设置 → 通知大家用新地址。
5. 旧的 Vercel 地址自动跳转到新地址，保留一个月，之后删掉 Vercel 项目。

切换时后台大约停用 30 分钟，读者网站不受影响。

## 五、需要你做的

- 注册 Google Cloud 账号（需要信用卡验证），并告诉我你用的是什么邮箱，以便写步骤。不要把卡号或密钥发给我。
- 在 Cloudflare 开通 R2（免费，但 Cloudflare 也会要求绑卡或 PayPal）。
- 切换那天，通知编辑部用新的后台地址。

## 需要你决定

1. **平台**：Google Cloud Run（推荐），还是其他？
2. **信用卡**：能不能找到一张卡（比如家长的）用来注册？不能的话，有没有能一直开机的电脑？
3. **图片**：同意搬到 Cloudflare R2 吗？或者继续用之前做好的 GitHub 图片仓库（不用绑卡，但单个仓库最好不超过 1 GB）。
4. **后台网址**：先用 Google 给的地址，还是你们有自己的域名？
